# README

## Обзор
Этот проект состоит из серверной части и клиентского приложения. Следуйте инструкциям ниже, чтобы настроить и запустить обе части приложения.

---

## Серверная часть (Backend)

### Инструкции по настройке

1. **Перейдите в папку сервера**
   ```bash
   cd backend
   ```
2. **Установите дополнительные зависимости**
   ```bash
   npm install
   ```
3. **Запустите сервер**
   ```bash
   npm run dev
   ```

## Клиентская часть (Frontend)

### Инструкции по настройке

1. **Перейдите в папку клиентской части**
   ```bash
   cd frontend
   ```
2. **Установите дополнительные зависимости**
   ```bash
   npm install
   ```
3. **Запустите клиентскую часть**
   ```bash
   npm start
   ```

## Устранение ошибок
Если вы столкнулись с ошибками в клиентской часим, выполните следующие команды для установки необходимых пакетов:
1. **Перейдите в папку клиентской части**
   ```bash
   npm install chart.js --save
   ```
2. **Установите дополнительные зависимости**
   ```bash
   npm install chartjs-plugin-datalabels --save
   ```
